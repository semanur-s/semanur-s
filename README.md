## 🧠 İlgi alanlarım

- **Bilgisayarlı görü:** nesne tespiti (YOLO), çoklu nesne takibi (ByteTrack, SORT), klasik görüntü işleme (filtreleme, köşe/öznitelik tespiti, SIFT/ORB, HOG)
- **Otonom sistemler:** hedef tespiti ve takibi, insansız hava araçları, hava savunma senaryoları
- **Kestirim ve takip:** Kalman filtreleri, hareket tahmini
- **Edge AI:** modelleri Raspberry Pi / Jetson gibi cihazlarda gerçek zamanlı çalıştırma (ONNX, quantization)
- **Derin öğrenme temelleri:** CNN mimarileri, sinir ağlarını sıfırdan yazmak
